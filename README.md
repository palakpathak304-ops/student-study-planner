# 📚 StudyFlow — Student Study Planner

> A simple and professional web-based study planner designed to help students
> organize their studies, track tasks, monitor progress, and stay motivated.

---

## ✨ About StudyFlow

**StudyFlow** is a student-focused study management application built with
HTML, CSS, and JavaScript.

It helps students manage their daily study activities through tasks,
subjects, goals, Pomodoro sessions, analytics, and achievement badges.

---

## 🚀 Features

- 📊 **Dashboard** — View overall study progress
- ✅ **Task Management** — Add, complete, search and filter tasks
- 📚 **Subject Tracking** — Manage subjects and topics
- 🎯 **Study Goals** — Set and track personal study goals
- ⏱️ **Pomodoro Timer** — Use focused study sessions
- 📈 **Analytics** — Monitor task completion and progress
- 🏆 **Achievements** — Unlock badges by completing milestones
- 🔥 **Study Streak** — Track consecutive study activity
- 🌙 **Dark Mode** — Switch between light and dark themes
- 💾 **LocalStorage** — Save study data in the browser
