📚 StudyFlow — Student Study Planner

A clean and interactive Student Study Planner designed to help students organize their studies, manage daily tasks, track subject-wise syllabus progress, set goals, and maintain consistent study sessions.

✨ Features
📊 Dashboard
Overview of total tasks and completed tasks
Study goals summary
Study streak tracking
Quick view of subjects and their progress
📖 Subject-wise Progress
First Year and Second Year subjects
Subjects divided into Units and Topics
Mark individual topics as completed
Automatic subject progress calculation
Unit-wise completion tracking
Progress is saved using LocalStorage
Option to reset/repeat subject progress
✅ Task Management
Add study tasks
Select subject and priority
Set due dates
Mark tasks as completed
Search and filter tasks
🎯 Study Goals
Create study goals
Track goal completion
Mark completed goals
⏱️ Pomodoro Timer
Focused study sessions
Start, pause and reset timer
Helps maintain productive study intervals
📈 Analytics
Completed task statistics
Overall completion rate
Subject-wise study progress
🏆 Achievements
Unlock achievements based on completed tasks
Encourages consistency and regular study
💾 LocalStorage

The application uses browser LocalStorage to save:

Tasks
Study goals
Completed topics
Progress data

Your data remains available even after refreshing the browser.

🛠️ Tech Stack
HTML5
CSS3
JavaScript
LocalStorage
⚙️ How It Works
Open the Dashboard to see your overall study activity.
Go to Subjects and select a subject.
Open a unit and mark completed topics using the checkboxes.
The subject progress percentage is automatically calculated.
Add daily study tasks from the Tasks section.
Create targets in Study Goals.
Use the Pomodoro Timer for focused study sessions.
Check Analytics to understand your progress.
Unlock Achievements as you complete more tasks.
All important progress data is stored in LocalStorage.

🚀 How to Run

No installation or backend setup is required.

Download or clone this repository.
Open the project folder.
Open index.html in a browser.

For development, you can also open the project using VS Code and run it with Live Server.

🎯 Project Purpose

The purpose of StudyFlow is to provide students with a simple digital workspace where they can plan, study, track, and improve their academic progress in one place.
